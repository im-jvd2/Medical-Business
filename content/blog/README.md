## نحوه‌ی استفاده

1. هر فایل یک مقاله است؛ بلوک «متادیتا» بالای هر فایل = فیلدهای سئو و دسته‌بندی در وردپرس (افزونه‌ی Rank Math / Yoast).
2. لینک‌های داخلی با **URL نهایی وردپرس** نوشته شده‌اند (مثل `/blog/...` و `/courses/...`)؛ هنگام بارگذاری، لینک‌ها را با ادیتور وردپرس اعمال کنید.
3. علامت 🔴 «جای داده واقعی» = نقطه‌ای که نیازمند داده/مثال واقعی و تأیید صریح مالک است؛ تا تأیید نشود، منتشر نشود.
4. عنوان H1 مقاله = سطر اول فایل؛ در وردپرس به‌عنوان عنوان پست وارد شود (H2 به بعد، داخل متن).
