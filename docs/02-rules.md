## ۲. قواعد بصری

- پالت رنگ: **آبی آسمانی + سفید** (جزئیات در [`06-design-system.md`](06-design-system.md)).
- طراحی باید **کاملاً ریسپانسیو** باشد (موبایل / تبلت / دسکتاپ).
- فاصله‌گذاری و اندازه‌ها باید از سیستم ثابت (Design System) پیروی کنند، نه مقادیر دلخواه.
- حداکثر ۲ خانواده فونت (عنوان + متن) استفاده شود.
- کنتراست متن و پس‌زمینه باید مطابق استاندارد دسترس‌پذیری (WCAG AA) باشد.

## ۴. قواعد فنی و عملکرد

- **سرعت**: امتیاز هدف در PageSpeed Insights ≥ ۹۰ (دسکتاپ) و ≥ ۷۰ (موبایل).
- تصاویر باید بهینه و فشرده باشند (WebP ترجیح داده می‌شود).
- **سئو پایه**: متاتگ عنوان و توضیحات، ساختار URL خوانا، نقشه سایت XML.
- **امنیت**: بکاپ‌گیری منظم، محدودسازی ورود، به‌روزرسانی هسته و افزونه‌ها.
- SSL فعال روی کل سایت.

## ۵. قواعد Git و همکاری

- شاخه‌ی `main` فقط حاوی نسخه‌ی تثبیت‌شده است.
- هر کار در شاخه‌ی جداگانه با نام استاندارد: `feature/…`, `fix/…`, `docs/…`.
- پیام کامیت: کوتاه، توصیفی و فارسی/انگلیسی یکدست.
- هیچ تغییر مستقیمی بدون PR روی `main` نرود.
- فایل‌های سنگین (ویدیو، موکاپ بزرگ، فایل‌های طراحی) در Git نگهداری نشود؛ لینک اشتراکی (Figma/Drive) جایگزین شود.
