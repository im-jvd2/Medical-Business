## ۴. مسیر کاربر (User Journey / Funnel)

```mermaid
flowchart LR
    A[ورود از گوگل/تبلیغ] --> B[صفحه فرود یا خانه]
    B --> C[مشاهده دوره]
    C --> D{اعتماد دارد؟}
    D -- بله --> E[ثبت‌نام / خرید یا فرم درخواست]
    D -- خیر --> F[مطالعه مقاله یا FAQ]
    F --> C
    E --> G[ورود به دوره / پنل کاربری]
```

> دوره پرچمدار (MBM) از مدل «Application Funnel» استفاده می‌کند: دکمه به‌جای خرید مستقیم، کاربر را به تکمیل فرم درخواست + تماس مشاوره برای پذیرش هدایت می‌کند.
