## ۳. محتوای هر خدمت (خلاصه‌ی ساختار تکرارشونده)

هر خدمت با این الگوی ثابت آمده است (هم‌راستا با الگوی «قالب تک‌شونده» در `04-content-map.md`):

1. **برچسب دسته** (Eyebrow): «خدمت n · دسته»
2. **`H2` ــ نام خدمت** (همراه نام لاتین در متن معرفی)
3. **پاراگراف مسئله/معرفی** — با تأکید بر درد واقعی مخاطب
4. **لیست خروجی‌ها (۴ تا ۶ مورد)** — هر مورد: عنوان پررنگ + توضیح یک‌خطی
5. **دو برچسب**: «مناسب برای: …» و «خروجی: …»
6. **دو CTA**: درخواست مشاوره (`#request`) + صفحه‌ی مرتبط

| خدمت | خروجی کلیدی (برچسب «خروجی») | CTA فرعی |
|------|------------------------------|-----------|
| عارضه‌یابی و استراتژی ۳۶۰ | نقشه‌راه مکتوب رشد درآمد | `contact.html` |
| سیستم‌سازی پذیرش | حداقل ۴۰٪ افزایش تبدیل تماس به نوبت قطعی | `course.html?c=rcp-301` |
| کمپین وفادارسازی و جذب بیمار | پر شدن تایم‌های خالی بدون تخفیف | `course.html?c=aes-201` |
| طراحی سایت | وب‌سایت آماده‌ی جذب بیمار + آموزش مدیریت محتوا | `contact.html` |
| طراحی دوره آموزشی پزشکی | دوره‌ی آماده‌ی عرضه با زیرساخت فروش و پنل | `courses.html` |

## ۴. قواعد رعایت‌شده (مطابقت با `02-rules.md`)

| قاعده | وضعیت در صفحه‌ی خدمات |
|-------|------------------------|
| یک `H1` در صفحه و ترتیب `H2 → H3` بدون پرش | ✅ `h1` یکتا در هیرو؛ سپس `h2`ها و `h3`های زیرمجموعه؛ آخرین تیتر قبل از فوتر `h3` است تا `h4`های فوتر پرش نشوند |
| لحن برند (تخصصی، بیزینسی، قاطع) | ✅ بدون اغراق و بدون وعده‌ی عددی نامستند |
| هر تصویر `alt` توصیفی | ✅ ۵ تصویر، همه با `alt` فارسی و `width/height` + `loading="lazy"` |
| طول عنوان ≤ ۶۰ کاراکتر | ✅ ۴۵ کاراکتر |
| متاتگ عنوان و توضیحات | ✅ هر دو (جدول §۱) |
| اسکیمای `FAQPage` برای بلوک FAQ | ✅ `application/ld+json` در پایان صفحه، متن پرسش/پاسخ **کلمه‌به‌کلمه** مطابق محتوای نمایشی |
| بدون رویداد درون‌خطی (`onclick`) | ✅ صفر مورد (فرم با کلاس `js-form` و رویداد `submit` مدیریت می‌شود) |
| بدون تکرار پرسش‌ها | ✅ ۶ پرسش این صفحه اختصاصی «خدمات» است و با پرسش‌های خانه/تماس/دوره/لندینگ تکرار ندارد (سوالات عمومی سایت → صفحه‌ی مرجع `/faq`) |
| طراحی کاملاً ریسپانسیو | ✅ با همان گرید و کلاس‌های سیستم طراحی (`grid-3`, `grid-4`, `split`) که رفتار موبایل/تبلت‌شان در `style.css` تعریف شده |
| رنگ و فاصله از سیستم طراحی | ✅ فقط توکن‌های موجود (`--blue`, `--blue-dark`, `--radius*`, `--shadow*`) و فواصل مضرب ۸ |
| بدون وابستگی سنگین و بدون فایل جدید | ✅ صفر تصویر/فونت/اسکریپت جدید؛ همه از `assets/` موجود |

### ⚠️ سه نکته‌ی مهم برای پیاده‌ساز

1. **فرم را با کلاس `js-contact-form` نسازید.** این کلاس باعث می‌شود فرم پس از ارسال از صفحه حذف شود (`main.js`). فرم این صفحه عمداً فقط `js-form` + `data-msg` دارد و پس از ارسال **بازنشانی** می‌شود و پیام موفقیت نشان می‌دهد. در وردپرس این فرم به افزونه‌ی فرم (Fluent Forms/WPForms) متصل شود و پیام موفقیت متن `data-msg` باشد.
2. **دکمه‌های «درخواست مشاوره» را به فرآیند ثبت‌نام دوره وصل نکنید.** این صفحه یک قیف مشاوره است، نه خرید؛ لنگر `#request` یا صفحه‌ی تماس. (باگ قیف لندینگ در گزارش بازبینی: `landing.html:183`).
3. **برای متن‌های آبی روی پس‌زمینه‌ی سفید، از `#1B5EA8` (کنتراست ۶.۵) استفاده کنید، نه `#2E86DE` (کنتراست ۳.۷۶)** — الزام WCAG AA در `02-rules.md`. رنگ اصلی برند همان `#2E86DE` می‌ماند اما برای متن/دکمه‌ی اصلی در المنتور Global Color تیره‌ی `#1B5EA8` تعریف شود.
