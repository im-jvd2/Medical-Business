# ۳ — برنامه‌ریزی اجرایی و تقسیم وظایف

> تبدیل نقشه راه به وظایف عملی. هر وظیفه = یک Issue در گیت‌هاب.

---

## ۱. تیم و نقش‌ها

| نقش | مسئولیت‌ها |
|------|-------------|
| مالک (Owner) | تصمیم‌گیری نهایی، تأیید محتوا و طراحی |
| طراح (Designer) | وایرفریم، UI، سیستم طراحی، موکاپ |
| توسعه‌دهنده (Developer) | پیاده‌سازی وردپرس/المنتور، سرعت، سئو فنی |
| ادیتور محتوا | تولید و بارگذاری محتوای متنی و تصویری |

---

## ۲. ماتریس مسئولیت (RACI خلاصه‌شده)

> R = مسئول اجرا، A = تأییدکننده، C = مشورت، I = مطلع

| وظیفه | مالک | طراح | توسعه‌دهنده | ادیتور |
|-------|:----:|:----:|:-----------:|:------:|
| تعیین برند و هویت | A | C | I | C |
| نقشه سایت | A | R | C | C |
| وایرفریم | A | R | C | I |
| سیستم طراحی | A | R | C | I |
| پیاده‌سازی صفحات | A | C | R | I |
| تولید محتوا | A | I | I | R |
| سئو و سرعت | A | C | R | C |
| انتشار | A | I | R | I |

---
