## 🎨 رابط کاربری (UI Mockup)

یک نمونه‌ی کامل و استاتیک از رابط کاربری سایت (HTML/CSS خالص، بدون وابستگی) در **ریشه‌ی همین ریپو** قرار دارد تا چیدمان المنت‌ها قبل از پیاده‌سازی وردپرس/المنتور دیده شود. چون صفحه‌ها در ریشه هستند، همین ریپو مستقیم روی **GitHub Pages** منتشر می‌شود (`index.html` به عنوان صفحه‌ی اصلی).

| فایل | صفحه |
|------|------|
| `index.html` | صفحه اصلی (خانه) |
| `courses.html` | آرشیو دوره‌ها (فیلتر و جستجو) |
| `course.html` | صفحه تکی دوره (پویا با `?c=course-id`) |
| `about.html` | درباره ما (ارزش‌ها، تیم، خط زمانی) |
| `blog.html` | وبلاگ (۹ مقاله با فیلتر دسته و جستجو) |
| `contact.html` | تماس با ما (فرم فعال + سوالات متداول) |
| `landing.html` | صفحه فرود (لندینگ) نمونه |
| `dashboard.html` | **پنل کاربری خریدار** (نمای کلی، دوره‌های من، سفارش/فاکتور، علاقه‌مندی، تیکت، پروفایل) |

### 🔑 ورود / ثبت‌نام و اکانت تستی (دمو)

- در همه صفحات، دکمه‌های «ورود / ثبت‌نام» یک **مودال** باز می‌کنند (تب‌های ورود و ثبت‌نام، اعتبارسنجی، نمایش/مخفی‌کردن رمز و...).
- داده‌ها در `localStorage` مرورگر ذخیره می‌شوند (شبیه‌سازی بک‌اند؛ در نسخه وردپرس به دیتابیس متصل می‌شود).
- **یوزر تستی:** نام کاربری `admin` / رمز `admin` — از قبل با ۴ دوره، سفارش و فاکتور، تیکت پشتیبانی و اعلان پر شده است.
- کاربر دوم برای تست: `sara` / `123456`
- گزینه «ورود سریع» داخل مودال هم همین اکانت را یک‌کلیکه وارد می‌کند.
- دکمه «خرید و ثبت‌نام در دوره»: کاربر مهمان را ابتدا به مودال ورود می‌برد و بعد از ورود، دوره به پنل اضافه می‌شود.

- استایل مشترک: `assets/css/style.css` (سیستم طراحی + انیمیشن‌ها + مودال) و `assets/css/dashboard.css` (مخصوص پنل)
- اسکریپت‌ها: `assets/js/data.js` (داده دموی دوره‌ها)، `main.js` (تعاملات، انیمیشن اسکرول، احراز هویت)، `course.js` (صفحه دوره پویا)، `dashboard.js` (پنل کاربری)
- فونت‌ها (میزبانی محلی): `assets/fonts/` — **آراد** برای عنوان‌ها، **یکان** برای متن
- تصاویر (میزبانی محلی): `assets/images/` — بنرهای هیرو و تصاویر محتوایی

> برای پیش‌نمایش محلی: `python3 -m http.server 8080` در ریشه‌ی ریپو، سپس `http://localhost:8080`

## 🤝 راهنمای مشارکت (برای طراح و توسعه‌دهنده)

1. قبل از هر کاری، `docs/02-rules.md` را کامل بخوانید — قواعد الزامی هستند.
2. هر تغییر را از طریق **Pull Request** اعمال کنید (نه کامیت مستقیم روی `main`).
3. هر صفحه/دوره/وظیفه = یک **Issue** با لیبل مناسب.
4. نمودارها را با **Mermaid** بکشید؛ تصاویر سنگین را در Git نگهداری نکنید (لینک Figma بدهید).
